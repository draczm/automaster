# AutoMaster

Сайт автосервиса на PHP + MySQL: онлайн-запись, календарь/расписание мастера, админ-панель.

## Демо-аккаунты

| Роль | Email | Пароль | Куда попадает |
|---|---|---|---|
| Администратор | admin@automaster.local | Admin123! | `admin/index.php` (записи, услуги, сотрудники, расписание) |
| Сотрудник | user@automaster.local | User123! | `master-schedule.php` (календарь и записи мастера) |
| Покупатель | client@automaster.local | Client123! | `profile.php` (автомобили, записи, бонусы) |

Клиенты могут зарегистрироваться сами на `register.php`.

## Запуск (XAMPP)

1. Скопируйте проект в `C:\xampp\htdocs\automaster`, запустите Apache и MySQL.
2. Импортируйте базу:
   ```bash
   mysql -uroot < database/schema.sql
   mysql -uroot < database/seed.sql
   ```
3. Откройте http://localhost/automaster/

Параметры БД по умолчанию: `localhost`, `root`, пустой пароль. Переопределяются переменными окружения `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`.

## Важно

GitHub Pages не выполняет PHP, поэтому репозиторий — это исходный код; для работающего сайта нужен PHP-хостинг с MySQL.
Демо-пароли публичные — смените их перед реальным использованием.
## Запуск онлайн в GitHub Codespaces

1. На странице репозитория: **Code → Codespaces → Create codespace on main**.
2. Дождитесь окончания установки (2–3 минуты): поднимутся PHP и MariaDB, база импортируется сама.
3. Во вкладке **Ports** найдите порт 8080, откройте его в браузере. Чтобы дать ссылку другим, правой кнопкой по порту → **Port Visibility → Public**.
4. Войдите под демо-аккаунтами из таблицы выше.

Codespace останавливается при простое; при повторном запуске сайт стартует снова.

## Онлайн-демо без сервера (GitHub Pages)

Статическая версия сайта лежит в папке `docs/` и открывается в любом браузере, PHP и база не нужны:
**https://draczm.github.io/automaster/**

- Вход: админ `admin@automaster.local` / `Admin123!`, сотрудник `user@automaster.local` / `User123!`, покупатель `client@automaster.local` / `Client123!`; подсказка есть на странице входа.
- Все страницы кликабельны, данные заполнены. Новая заявка из формы записи сохраняется в браузере и появляется в календарях, списках и кабинете (видна только в этом браузере; кнопка «Сбросить мои заявки» внизу слева). Остальные формы изменения не сохраняют.
- Пересобрать после правок: поднять PHP на демо-базе и выполнить `python tools/build_static.py http://127.0.0.1:8099` (см. шапку скрипта).
